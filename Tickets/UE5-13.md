# UE5-13 — массовое удаление Landscape Paint Target Layers

Источник: https://bodomus.youtrack.cloud/issue/UE5-13/UE57Editor-massovoe-udalenie-Landscape-Paint-Target-Layers

## Цель

Добавить в UE57Editor безопасное массовое удаление Paint Target Layers выбранного Landscape. Результат должен быть эквивалентен последовательному нажатию штатной кнопки X у каждого Target Layer, но выполняться одной подтверждаемой операцией с одним Undo/Redo.

## UI

- секция `Landscape Paint Layers` в существующей панели;
- имя выбранного Landscape и кнопка Refresh;
- список слоёв с checkbox, именем, LayerInfo asset, типом blending, признаком присутствия в материале и orphaned;
- Select All, Select None, Invert;
- Remove Selected и Remove All;
- операция доступна только когда в Editor выбрано ровно одно `ALandscape`/`ALandscapeProxy`;
- перед удалением показывается подтверждение с количеством и именами слоёв и предупреждением о потере paint-данных; для Remove All требуется усиленное предупреждение.

## Безопасность и поведение

- использовать штатный публичный путь Unreal удаления Paint Target Layer;
- одна `FScopedTransaction` на всю массовую операцию;
- вызвать `Modify()` для изменяемых UObject через штатный путь движка;
- корректные Undo/Redo, dirty state и обновление Landscape/editor UI;
- не удалять `ULandscapeLayerInfoObject` assets;
- не изменять Landscape Material;
- предварительно валидировать весь набор, чтобы неизвестные/дублирующиеся слои не приводили к частичному удалению;
- частичный результат нельзя объявлять полным успехом.

## Архитектура и автоматизация

- выделить сервис, независимый от Slate UI;
- предоставить editor-only `UBlueprintFunctionLibrary`, доступную из Unreal Python;
- Python-вызов обязан требовать явное подтверждение (`confirm=True`) и возвращать структурированный результат;
- добавить тесты для чистой логики валидации/выбора, а интеграционные ограничения описать отдельно.

## Проверка

- null/нет выбора/множественный выбор;
- пустой набор, один и несколько слоёв, неизвестный слой, дубликаты;
- сохранение невыбранных слоёв, LayerInfo assets и материала;
- одна операция Undo/Redo;
- обновление списка и viewport после удаления;
- сборка UE 5.7 Editor и автоматические тесты плагина.
