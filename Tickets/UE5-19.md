# UE57Editor — ScanVault Importer v1

## Summary

Добавить в **UE57Editor** importer существующего ScanVault manifest schema v1 (`*.scanvault-ue.json`), создаваемого MLV-14.

UE57Editor должен:

- прочитать и валидировать manifest;
- импортировать textures;
- импортировать primary mesh;
- импортировать LODs;
- resolve Master Material;
- создать Material Instance;
- назначить active texture parameter mappings;
- применить declarative import options;
- назначить Material Instance mesh;
- сохранить UE assets;
- сформировать import report.

Ключевой принцип: **ScanVault уже определил, что есть что. UE57Editor не должен повторно угадывать semantic roles по именам файлов.**

## Goals

1. Импортировать один ScanVault manifest в UE 5.7.
2. Валидировать schemaVersion.
3. Валидировать package structure.
4. Валидировать source files.
5. Импортировать declared textures.
6. Импортировать declared primary mesh.
7. Импортировать declared LODs.
8. Resolve Master Material.
9. Create Material Instance when requested.
10. Assign only active mappings from manifest.
11. Respect:
    - `importLods`;
    - `enableNanite`;
    - `createMaterialInstance`.
12. Assign MI to imported mesh.
13. Save generated assets.
14. Produce deterministic import report.
15. Avoid partial/broken UE content after failure.
16. Keep source library read-only.

---

## Non-goals

Не включать в v1:

- ScanVault launch;
- IPC / HTTP / sockets;
- folder watching;
- automatic reimport monitoring;
- material graph generation;
- automatic Master Material creation;
- texture packing/unpacking;
- Gloss -> Roughness pixel inversion;
- mesh geometry processing;
- advanced collision generation;
- Foliage Type creation;
- PCG asset creation;
- Landscape Layer creation;
- Blueprint generation;
- batch variants import;
- source conversion;
- schemaVersion > 1.

# 3. Schema handling

Supported:

```text
schemaVersion == 1
```

If `schemaVersion > 1`:

```text
This ScanVault package was created by a newer manifest schema version.
UE57Editor currently supports schemaVersion 1.
```

If missing/invalid:

```text
Invalid ScanVault manifest schema.
```

Не делать best-effort import неизвестной версии.

# 5. ScanVault validation state

Если manifest содержит blocking validation errors:

- показать их в preview;
- Import disabled by default.

Если ScanVault package уже содержит explicit override:

- показать отдельный warning;
- запросить второе явное подтверждение перед UE import.

Warnings:

- не блокируют;
- показываются в preview;
- входят в final report.

# 9. Existing asset conflicts

До импорта проверить конфликты:

```text
Static Mesh exists
Texture exists
Material Instance exists
Destination contains previous assets
```

Никакого silent overwrite.

Минимальная v1 policy:

```text
Cancel
Import with unique suffix
```

Если безопасный overwrite уже поддерживается архитектурой UE57Editor, можно добавить:

```text
Overwrite generated assets
```

но только после investigation и с защитой pre-existing user assets.

# 12. Texture settings

Минимально:

### BaseColor

```text
sRGB = true
```

### Normal

```text
sRGB = false
CompressionSettings = Normalmap
```

### Roughness / AO / Displacement / Opacity / Specular

```text
sRGB = false
```

### Translucency

Исследовать фактический UE 5.7 use-case и документировать принятое решение.

Не изменять pixels.

Если semantic role = Roughness, но manifest `mapType = Gloss`:

- не выполнять pixel inversion;
- добавить warning:

```text
Original map type is Gloss. No pixel inversion was performed.
```

# 13. Primary mesh import

Использовать manifest `mesh.primaryVariant` и declared LOD entries.

Primary/base mesh выбирается manifest'ом.

Не выбирать другой FBX по filename.

Recommended UE name:

```text
SM_<AssetBaseName>
```

---

# 14. LOD import

Если:

```text
options.importLods == true
```

- import primary mesh as base;
- attach further LODs in declared `lod` order;
- validate duplicate LOD indexes;
- validate invalid/gapped numbering;
- report inconsistencies.

Если:

```text
options.importLods == false
```

- import primary mesh only;
- report skipped LOD count.

Не сортировать LOD по filename.

# 17. Master Material resolution

Resolve manifest Master Material through Unreal Asset Registry/object loading.

Validate:

```text
path valid
asset exists
asset is compatible MaterialInterface
```

Missing:

```text
Master Material not found
```

If `createMaterialInstance=true` — block MI stage.

---

# 18. Material Instance

If:

```text
options.createMaterialInstance == true
```

Create `MaterialInstanceConstant`.

Использовать manifest MI name/prefix when provided by schema.

Parent:

```text
manifest.material.masterMaterialPath
```

Не создавать новый Master Material.

---

# 19. Texture parameter mappings

Критическое правило MLV-14:

```text
mapping present -> assign
mapping absent  -> do not assign
```

Не восстанавливать disabled mappings из defaults.

Для каждого active mapping:

1. найти imported texture by semantic role;
2. проверить параметр у parent/MI;
3. assign texture.

Missing parameter:

- warning;
- continue other mappings;
- include exact parameter name in report.

---

# 20. Nanite

If:

```text
options.enableNanite == true
```

and imported asset is compatible Static Mesh:

- enable Nanite using UE 5.7 API;
- save actual result.

Failure:

- warning unless mesh becomes invalid.

`false` must be respected.

No filename-based Nanite inference.

---

# 21. Assign MI to mesh

After MI creation:

- assign MI to mesh material slot(s).

Safe v1 rule:

```text
1 slot  -> assign automatically
>1 slot -> explicit policy required after investigation
```

Не назначать blindly на все slots без анализа реальных Megascans meshes.

Implementation plan должен описать multi-slot policy.

---

# 22. Save assets

After successful stages:

- mark generated assets dirty;
- save packages;
- verify save success.

Potential generated asset classes:

```text
Texture2D
StaticMesh
MaterialInstanceConstant
```

Save failure must affect final status.

---

# 23. Failure and cleanup

UE imports are not DB transactions.

Minimum strategy:

1. Track all assets created in current import session.
2. On failure:
   - stop remaining stages;
   - attempt safe cleanup of assets created by this session only.
3. Never delete pre-existing assets.
4. If cleanup incomplete:

```text
PartialImport
```

and list leftovers.

Не заявлять atomic import, если это не гарантировано.

# 31. Read-only source guarantee

Importer never:

- modifies textures;
- modifies FBX/ABC;
- renames source files;
- deletes source files;
- moves source files;
- alters ScanVault DB;
- alters manifest.

Only UE project content may change.
