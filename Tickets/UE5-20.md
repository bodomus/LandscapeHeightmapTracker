# UE5-20 — LandscapeHeightmapTracker: 3D-маркеры вдоль изолинии

- URL: https://bodomus.youtrack.cloud/issue/UE5-20/LandscapeHeightmapTracker-3D-markery-vdol-izolinii
- Тип: Задание
- Приоритет: Обычная
- Состояние на начало работ: Открыта

## Контекст и цель

Плагин уже рассчитывает и показывает изолинии на 2D-карте. Для каждой строки
изолинии нужно добавить создание разреженной последовательности вертикальных
box-маркеров непосредственно в мире Unreal Editor.

## UI

Для каждой изолинии нужны действия:

- `Create 3D Boxes`;
- `Update 3D Boxes`;
- `Delete 3D Boxes`.

`Update` и `Delete` недоступны или скрыты, пока набор не создан. Повторный
`Create` не создаёт дубликаты.

## Параметры и defaults

- `Box Length`: 10 м;
- `Box Height`: 10 м;
- `Box Thickness`: 2 м;
- `Gap Length`: 10 м;
- `Z Offset`: настраиваемый.

`PlacementStep = BoxLength + GapLength`, поэтому default-шаг равен 20 м.

## Размещение

1. Использовать уже рассчитанную полилинию выбранной изолинии.
2. Преобразовать точки heightmap/2D-карты в world coordinates существующим
   проверенным преобразованием плагина.
3. Передискретизировать равномерно по накопленной длине, а не по индексам точек.
4. Центр box по XY соответствует центру занимаемого участка линии.
5. Ось длины направлена по касательной; применять только Yaw.
6. Нижняя грань лежит на высоте изолинии:
   `CenterZ = ContourWorldZ + BoxHeight / 2 + ZOffset`.
7. Для замкнутого контура корректно обработать шов без двойного элемента.
8. Короткие фрагменты, недостаточные для полного box, не создают вырожденную
   геометрию.

## Архитектура

- Один editor-only actor на изолинию (например, `ALHTContourBoxesActor`).
- Один `UHierarchicalInstancedStaticMeshComponent` или
  `UInstancedStaticMeshComponent`; один instance на box.
- Стандартный Unreal cube mesh либо plugin-owned mesh, без создания assets.
- Один материал/цвет набора, соответствующий цвету изолинии.
- Не использовать отдельный `AStaticMeshActor` на каждый box и не использовать
  spline mesh без отдельной необходимости.

Actor помещается в папку вида
`LandscapeHeightmapTracker/GeneratedContours/Height_<Value>` и получает
стабильное читаемое имя. Он хранит устойчивый ID исходной изолинии и editor
tag/metadata. Изолинии одинаковой высоты не конфликтуют; управление не должно
затрагивать пользовательские actor или другие изолинии.

## Editor-only требования

- `NoCollision`;
- actor и компоненты editor-only, скрыты в игре и не попадают в cooked build;
- Landscape, heightmap, слои и исходные контуры не изменяются;
- Create/Update/Delete поддерживают Undo/Redo через `FScopedTransaction` и
  `Modify()`;
- package/level помечается dirty только при реальном изменении;
- отсутствие Landscape, смена level и World Partition обрабатываются безопасно
  с понятным сообщением;
- тяжёлые операции не выполняются в Slate paint/tick;
- UObject/Actor создаются и меняются на game/editor thread;
- валидировать положительные размеры, неотрицательный gap и ограничивать число
  instances.

## Критерии приёмки

- [ ] В каждой строке есть `Create 3D Boxes`.
- [ ] На Landscape создаются вертикальные box вдоль выбранной изолинии.
- [ ] Default box: 10 × 2 × 10 м; gap 10 м; placement step 20 м.
- [ ] Box ориентированы по касательной и не получают Pitch/Roll Landscape.
- [ ] Нижняя грань соответствует высоте изолинии с учётом `Z Offset`.
- [ ] Одна изолиния представлена одним actor с HISM/ISM instances.
- [ ] Actor организован в отдельной папке Outliner и удаляется одной операцией.
- [ ] Повторный Create не создаёт дубликаты.
- [ ] Update перестраивает существующий набор.
- [ ] Delete удаляет только выбранный набор.
- [ ] Одинаковая высота разных изолиний не вызывает конфликт.
- [ ] Замкнутые и разорванные контуры обработаны корректно.
- [ ] Create/Update/Delete поддерживают Undo/Redo.
- [ ] Маркеры editor-only, скрыты в игре/cooked build, collision выключен.
- [ ] Существующее 2D-отображение и другие функции не нарушены.

## Автоматические тесты

Минимально покрыть:

1. шаг 10 м + 10 м = 20 м;
2. прямую полилинию и число transforms;
3. ориентацию горизонтального, вертикального и диагонального участков;
4. `CenterZ` с высотой и offset;
5. замкнутый контур без дубля на шве;
6. короткий фрагмент;
7. одинаковую высоту с разными ID;
8. Create/Update/Delete без дублей и посторонних удалений;
9. Undo/Redo создания и удаления;
10. лимит instances и отсутствие тысяч отдельных actor.

## Ручная проверка и результат

Проверить 2D↔3D соответствие, gaps, ориентацию, Z, Outliner, ручное удаление,
Update параметров/геометрии, Undo/Redo и отсутствие маркеров в PIE/cooked build.
Предоставить архитектуру, изменённые файлы, способ идентификации, результаты
тестов, оценку производительности и скриншоты. Merge не выполнять до
пользовательской визуальной проверки.
