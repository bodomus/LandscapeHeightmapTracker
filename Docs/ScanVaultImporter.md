# ScanVault Importer

`ScanVault Import Package` imports a single ScanVault Unreal manifest generated by MLV-14.

## Supported Schema

Only `schemaVersion` 1 is supported. Missing, invalid, or newer schemas are rejected before any Unreal assets are created.

## Entry Point

Use:

```text
Tools -> Landscape Heightmap Tracker -> ScanVault Import Package
```

The file picker accepts:

```text
*.scanvault-ue.json
*.json
```

## Import Flow

1. Select a manifest.
2. UE57Editor parses JSON with Unreal JSON facilities.
3. The importer validates schema, required sections, destination path, declared source files, ScanVault validation state, and LOD consistency.
4. A preview window shows package, destination, mesh, textures, material, options, and validation messages.
5. The user confirms import.
6. The importer creates Unreal assets, saves packages, and shows a final report. The report is also copied to the clipboard.

## ScanVault Boundary

ScanVault is authoritative for:

- asset identity;
- primary mesh selection;
- LOD order and indexes;
- texture semantic roles;
- material profile snapshot;
- active texture parameter mappings;
- destination suggestion;
- import options.

UE57Editor does not infer texture roles from filenames, search for alternate files, modify source assets, or modify the manifest.

## Destination

`destination.contentPath` must be a valid `/Game/...` long package path. Invalid paths block import. The importer never silently redirects to another folder.

## Naming

Default generated names:

```text
T_<AssetBaseName>_BC
T_<AssetBaseName>_N
T_<AssetBaseName>_R
T_<AssetBaseName>_AO
T_<AssetBaseName>_D
T_<AssetBaseName>_O
T_<AssetBaseName>_S
T_<AssetBaseName>_T
SM_<AssetBaseName>
MI_<AssetBaseName>
```

The manifest Material Instance name is used when present.

## Conflicts

There is no silent overwrite.

Preview offers:

- `Cancel on conflict`;
- `Import with unique suffix`.

The unique suffix path uses Unreal AssetTools unique naming and reports every rename.

## Texture Settings

- `baseColor`: `sRGB=true`.
- `normal`: `sRGB=false`, normal map compression.
- `roughness`, `ao`, `displacement`, `opacity`, `specular`, `translucency`, `other`: `sRGB=false`.

If role is `roughness` and original `mapType` is `gloss`, no pixel inversion is performed and the report contains a warning.

## Mesh and LODs

The primary mesh is `mesh.lods[0]` with `lod=0`. When `options.importLods=true`, further LODs are imported in declared LOD order using the UE 5.7 static mesh editor subsystem. Duplicate indexes and gaps block import.

When `options.importLods=false`, only LOD 0 is imported and skipped LOD count is reported.

## Material Instance

When `options.createMaterialInstance=true`:

- `material.masterMaterialPath` is loaded as `UMaterialInterface`;
- a `UMaterialInstanceConstant` is created;
- only mappings present in the manifest are assigned;
- missing parent texture parameters are warnings, not fatal errors.

Disabled/absent mappings are not recreated from defaults.

## Material Slot Policy

If the imported mesh has exactly one material slot, the created MI is assigned to slot 0.

If the mesh has more than one slot, the importer leaves assignments unchanged and reports a warning. Multi-slot policy is intentionally deferred until real asset cases are reviewed.

## Nanite

When `options.enableNanite=true`, Nanite is enabled on the imported static mesh through UE 5.7 static mesh settings and the mesh is rebuilt. Failure is reported as a warning.

When false, Nanite is not enabled by the importer.

## Cleanup

Unreal imports are not transactional. The importer tracks assets created during the current session and, on fatal failure, attempts to delete only those assets. Pre-existing assets are never deleted. If cleanup is incomplete, the report status is `PartialImport` and leftover object paths are listed.

## Known Limitations

- Only one manifest is imported at a time.
- No ScanVault process launch, IPC, folder watching, or reimport monitoring.
- No Master Material creation.
- No material graph generation.
- No texture packing/unpacking or gloss-to-roughness pixel inversion.
- Multi-slot mesh material assignment is warning-only in v1.
- Full validation requires real ScanVault manifests and an interactive UE 5.7 editor session.
