# UE5-13 implementation report

## Result

Implemented bulk removal of Landscape Paint Target Layers in the existing
UE57Editor Landscape panel.

## Implementation

- FLandscapePaintLayerService centralizes exact-one selection, enumeration,
  validation and removal independently of Slate.
- All requested names are validated before starting a single FScopedTransaction.
- Removal uses UE 5.7's public ULandscapeInfo::DeleteLayer under
  FScopedSetLandscapeEditingLayer, matching the stock Target Layer X handler.
- The engine path modifies the Landscape actor, proxies and components, clears
  component weightmap allocations, dirties packages, updates layer maps and
  requests layer-content refresh.
- SLandscapePaintLayerBulkRemoveWidget provides Refresh, per-layer selection,
  Select All/None/Invert, Remove Selected/All and detailed confirmation.
- ULandscapePaintLayerLibrary exposes query, selected removal and remove-all to
  Unreal Python with mandatory explicit confirmation and structured results.
- LayerInfo assets and Landscape materials are never deleted or modified.
